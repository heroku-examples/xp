OVERVIEW
--------
This Docker-based setup simulates a Heroku dyno environment for testing the
XP plugin's traffic routing capabilities locally.

TESTING SCENARIOS
-----------------
The setup includes 5 pre-configured test scenarios:

1. Weight-Based Routing (10%)
   - 10% of traffic → experiment-1
   - 90% of traffic → parent-app

2. Path-Based Routing
   - /experiment/* → experiment-1
   - / → parent-app

3. Query Parameter Routing
   - /?exp=1 → experiment-1
   - / → parent-app

4. Header-Based Routing
   - X-Experiment: exp-1 → experiment-1
   - No header → parent-app

5. Multi-Experiment Setup
   - /api/v2 → experiment-1
   - /?beta=true → experiment-2
   - / → parent-app

AUTOMATED TEST RUNNER
---------------------
./test-scenarios.sh commands:

  weight    - Test weight-based routing
  path      - Test path-based routing
  query     - Test query parameter routing
  header    - Test header-based routing
  multi     - Test multi-experiment setup
  config    - View generated Traefik configuration
  logs      - View service logs
  cleanup   - Stop all services
  all       - Run all test scenarios sequentially

Example:
  ./test-scenarios.sh weight
  ./test-scenarios.sh config
  ./test-scenarios.sh cleanup

TEST APP ENDPOINTS
------------------
The Express.js test app includes these endpoints:

GET  /                → Root endpoint (shows app identity)
GET  /health          → Health check
GET  /api/*           → API endpoints for path testing
ANY  /experiment*     → Experiment endpoints for path testing
ANY  /echo            → Echo request details
POST /users           → User endpoint for JSON body testing
POST /products        → Product endpoint for JSON body testing
GET  /slow?delay=ms   → Slow endpoint (latency testing)
GET  /error           → Returns 500 error
GET  /load?iterations → CPU load endpoint

CONFIGURATION
-------------
Set HEROKU_EXPERIMENTS environment variable to configure routing:

export HEROKU_EXPERIMENTS='{
  "version": 1,
  "experiments": {
    "exp-1": {
      "name": "exp-1",
      "appName": "xp-experiment-1",
      "status": "active",
      "routing": {
        "weight": 10,
        "paths": ["/experiment"],
        "queries": {"exp": "1"},
        "headers": {"x-experiment": "exp-1"}
      }
    }
  }
}'

docker-compose up parent-app experiment-1

DEBUGGING
---------
View Traefik config:
  ./test-scenarios.sh config
  
  OR
  
  docker exec xp-parent-app cat /app/.heroku/traefik/config/dynamic/experiments.yml

View logs:
  docker-compose logs -f parent-app
  docker-compose logs -f experiment-1

Access Traefik dashboard:
  open http://localhost:8081

Shell access:
  docker exec -it xp-parent-app bash
  docker exec -it xp-experiment-1 bash

COMMON ISSUES
-------------
1. Port already in use
   → Kill process: lsof -i :8080 && kill <PID>
   → Or change port in docker-compose.yml

2. Traefik not starting
   → Rebuild: docker-compose build --no-cache parent-app

3. Experiment not receiving traffic
   → Check status in HEROKU_EXPERIMENTS (must be "active")
   → Verify config: ./test-scenarios.sh config
   → Restart: docker-compose restart parent-app

4. Configuration not applied
   → Restart parent app: docker-compose restart parent-app
